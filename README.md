# Agricultural Input Rebate Recovery

Capture supplier rebates and loyalty incentives earned through acres, product bundles, volume, and program compliance.

**Primary buyer:** Farms, cooperatives, and agricultural retailers. **Evidence:** seed chemical and fertilizer agreements, farms, products, purchases, acres, application records, volume tiers, bundles, loyalty programs, claims, and credits.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Supplier program library
- Farm account registry
- Product eligibility mapping
- Purchase transaction ingestion
- Acre application evidence
- Volume tier calculation
- Product bundle validation
- Early order incentive
- Loyalty status control
- Return exclusion
- Rebate claim preparation
- Supplier statement audit
- Dispute workflow
- Credit cash reconciliation
- Farm supplier analytics

Run `./start.sh`, then open <http://127.0.0.1:4710>. API: `5710`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
